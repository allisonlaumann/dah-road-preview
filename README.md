# DAH Road (working name)

A mobile-first guide for sports parents to the venues where their kids play: parking,
bathrooms, food, "pack for the day" lists and live conditions from other parents.

**Preview build.** Venue addresses are real. Sample venues, parents, posts and businesses
are made up and labeled. Posts and sign-ups are saved only in your own browser until the
shared database is turned on (see `backend/SETUP.md`).

- `index.html`, `css/`, `js/`: the site (no build step; it's plain HTML/JS)
- `js/data.js`: site name and sample data · `js/venues-real.js`: real venues
- `logo/`: logo drafts
- `backend/`: database plan for Supabase
